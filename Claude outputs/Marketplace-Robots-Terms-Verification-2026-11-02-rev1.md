## 조사 결과와 기입 기준

16개 robots.txt URL 모두 조회를 시도했다. 반환 본문을 확보한 곳은 쿠팡 1곳이며, 나머지 15곳은 본문 미확보다. 조회 실패는 사이트의 허용/금지 규칙, 파일 부재 또는 실제 HTTP 상태를 증명하지 않는다.

공개 약관과 콘텐츠 이용 안내에서는 미트박스의 스크랩 제한, 허브온의 콘텐츠 이용 제한, 여러 전문몰의 영리 목적 재사용 제한, 네이버의 자동화 접근 예외 조건을 확인했다. robots.txt와 약관은 따로 기록했다. 특정 봇 차단은 다른 봇·다른 호스트의 지시로 일반화하지 않는다.

**G등급은 전 행 미판정이다.** 전달된 인용문과 현재 확인한 기존 MD에는 G등급의 정의·상위 판정 규칙이 없다. 따라서 임의로 G0/G1 등을 만들거나 업체에 배정하지 않았다. 아래 “제한 확인”, “권한 확인 필요”는 사실 요약·운영 검토 의견이며 G등급이나 법적 허용/금지 확정이 아니다. 등급 정의가 제공되더라도 실제 수집 경로·목적·대상 URL·허용 근거를 함께 검토해야 한다.

### 약관과 AI 관련 해석의 한계

- “AI 학습 허용 근거 미확보”는 학습 조항이 모든 관련 문서에 존재하지 않는다는 판정이 아니다. 접근한 텍스트의 검색 무결과도 전체 정책의 부재 증명이 아니다.
- 영리 재사용 제한은 해당 회사에 권리가 귀속된 정보 등에 관한 조항의 요약이다. 모든 사실값·모든 이용을 전면 금지한다는 법률 결론으로 확장하지 않는다.
- 사이트가 자신의 회원 게시물·행태정보를 사용할 수 있다는 조항은 우리 서비스가 수집·저장·모델에 전송하거나 학습할 수 있다는 허가가 아니다.
- robots.txt의 허용 또는 전용 AI 봇 항목 부재만으로 상품정보 저장·재표시·상업 이용·AI 학습 권한을 인정하지 않는다.
- 사용자 직접 링크 열기, 우리 서버의 자동 수집, 외부 LLM 추론 전송, 모델 학습, 결과 재배포를 각각 별도 사용 목적으로 검토한다.
- 이번 조회 도구의 실제 요청 User-Agent·원 서버 응답 헤더·반환 bytes 전체는 확보하지 않았다. 반환된 정책 텍스트를 해석한 결과와 우리 collector 실행 적격성을 구분한다.

### §12 기존 “검증 수준” 문단의 대체 문안

> 본 문서 §12.1은 2026-11-02 ChatGPT의 공개 웹 조회 결과를 반영한다. 16개 robots.txt URL 중 쿠팡은 반환 본문에서 일반 및 주요 AI 봇 차단을 확인했고, 나머지 15곳은 조회 시도 후 본문 미확보로 기록했다. 공개 약관·사이트 이용 안내의 확인 조항과 미확보 조항을 구분했으며, 사용자 수동 검증이나 업체의 수집 허가 취득으로 집계하지 않는다. G등급 정의·실제 수집 목적과 경로별 허용 근거가 확립되지 않아 G등급은 전 행 미판정이다. §7의 등급 관련 서술과 §7.1의 검증 대기 목록은 본 표만으로 확정·갱신하지 않는다. 확인된 사실과 보류 사유만 기록하고, 접근 실패나 AI의 추정을 허용 근거로 사용하지 않는다.

기존 인용문의 “어떤 값도 검증되지 않았다”는 표현은 이번에 실제 확인한 조항까지 미확인으로 되돌리므로 그대로 유지하지 않는다. 다만 “모든 미확인 항목 해소”나 “G등급 확정”으로 바꾸지도 않는다.
