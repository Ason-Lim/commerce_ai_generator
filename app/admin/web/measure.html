클릭·구매 연결
측정용이에요 — 추천 순위에 쓰지 않아요.

노출·클릭은 상품 번호만(상품명·가격 없음). 시험 브라우저는 /test-mode/on 을 한 번 열면 '시험'으로 따로 세요(끄기 /test-mode/off).

쿠팡 리포트는 매일 scripts/coupang_report_daily.py 로 최근 30일을 다시 받아요(오후 3시 30분 뒤). 금액은 이 화면에만 — 문서·커밋에 쓰지 않아요.

기간 보고

노출(대화) → 클릭(우리 /go) → 쿠팡 클릭 → 주문(추정) → 취소. 주는 월~일, 달은 1일~말일(기간 양 끝은 고른 날짜에 맞춰 잘림).
