폐쇄몰 1차 — 기업 일괄 구매형. 직원 확인은 발주처가 해요: 여기서 인원 수만큼 코드를 만들어 발주처 담당자에게 넘기면, 발주처가 직원에게 나눠 줘요. 우리는 명단을 받지 않아요.

우리가 보장하는 건 코드 하나에 주문 하나까지예요. 직원 한 명에 코드 하나 배포, 공유·대리 사용은 발주처 몫(계약서·안내문에 적기).

코드마다 초대 링크(긴 토큰)와 직접 입력 코드(8자)가 같이 나와요. 링크를 여는 것만으로는 소진되지 않아요.

코드 원문은 만들 때 한 번만 보여요 — 바로 내려받으세요(서버에는 해시만).

배송 정보는 직원이 고를 때만, 암호화해 보관하고 배송 완료 뒤 보존 기간이 지나면 지워요. 내보내기 파일은 공급사 전달 뒤 지워 주세요.
