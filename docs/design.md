# Commerce AI Generator Design v0.1

## 1. 서비스 정의

Commerce AI Generator는 사용자의 검색 의도와 상품 데이터를 결합하여 최적의 상품을 추천하는 AI Commerce 서비스다.

단순 최저가 추천이 아니라 다음 요소를 함께 평가한다.

- 가격
- 품질
- 신뢰도
- 사용자 반응
- 추천 맥락

---

## 2. 핵심 방향

Commerce AI는 사용자가 직접 비교하지 않아도 되도록 한다.

기존 쇼핑몰 흐름:

검색 → 상품 리스트 → 사용자가 직접 비교 → 구매

Commerce AI 흐름:

상황 입력 → AI 분석 → 추천 이유 생성 → 최적 상품 추천 → 상품 페이지 이동

---

## 3. 비교 플랫폼

초기 비교 플랫폼은 다음과 같다.

- 네이버쇼핑
- 쿠팡
- 컬리
- 이마트몰
- 우체국쇼핑

플랫폼은 계속 추가될 수 있으므로 크롤러 중심이 아니라 platform_master 중심으로 관리한다.

---

## 4. 플랫폼 확장 원칙

각 플랫폼은 다음 기준으로 관리한다.

- platform_code
- platform_name
- parent_platform
- base_domain
- crawler_type
- is_active
- priority
- category_strength
- memo

새로운 플랫폼을 추가할 때는 먼저 platform_master에 등록하고, 이후 수집기 또는 API 연동 여부를 결정한다.

---

## 5. UI 구조

### 5.1 검색 영역

사용자는 자연어로 원하는 상품 조건을 입력한다.

예시:

- 당도 높은 사과 선물용
- 가성비 좋은 복숭아
- 부모님 선물용 배
- 리뷰 좋은 고당도 과일

---

### 5.2 추천 모드

추천 모드는 다음과 같다.

- ranking: 종합 추천
- price: 가성비 추천
- quality: 품질 추천
- trust: 신뢰 추천
- exploration: 탐색 추천
- revisit: 재방문 추천

unknown은 정상 추천 모드로 사용하지 않는다.

---

## 6. Hero 추천 카드

Hero 카드는 1위 추천 상품을 강조하는 영역이다.

### 구성 요소

- 순위
- 상품명
- 판매처
- 가격
- 추천 이유
- 정보 칩
- 상품 보러가기 CTA

### 디자인 원칙

- 1위 상품임을 명확하게 보여준다.
- 추천 이유는 최대 3개로 제한한다.
- CTA는 하나만 제공한다.
- 클릭 시 백그라운드 로그 저장 후 상품 페이지로 이동한다.

---

## 7. 2~4위 추천 카드

2~4위 카드는 대안 상품을 비교할 수 있도록 보여준다.

### 디자인 원칙

- 카드 높이를 통일한다.
- 그림자와 여백을 통일한다.
- CTA 버튼 스타일을 통일한다.
- 추천 이유 표현 방식을 Hero 카드와 일관되게 유지한다.

---

## 8. 추천 점수 구조

추천 점수는 다음 요소를 종합한다.

- price_score
- quality_score
- trust_score
- engagement_score

기본 가중치 예시:

price_score 30%

quality_score 30%

trust_score 20%

engagement_score 20%

향후 추천 모드에 따라 가중치를 다르게 적용한다.

---

## 9. 클릭 로그 원칙

상품 CTA 클릭 시 반드시 로그를 저장한다.

필수 수집 항목:

- session_id
- product_id
- product_name
- rank
- recommendation_mode
- platform
- mall_name
- price
- clicked_at

recommendation_mode가 unknown으로 저장되는 것은 오류로 간주한다.

---

## 10. 사용자 반응 기반 추천

사용자 반응은 추천 품질 개선에 사용한다.

수집 대상:

- 노출
- 클릭
- 관심
- 재방문
- 구매 전환

초기 단계에서는 클릭 로그를 우선 활용한다.

---

## 11. 동일상품 매칭

Commerce AI는 서로 다른 플랫폼의 유사 상품을 비교한다.

예시:

네이버 상품 → 쿠팡 동일상품 → 컬리 동일상품 → 이마트몰 동일상품

판단 기준:

- 상품명
- 브랜드
- 품종
- 중량
- 가격 단위
- 이미지
- 판매처

---

## 12. AI 추천 설명

사용자는 추천 이유를 쉽게 이해할 수 있어야 한다.

예시:

이 상품은 가격 경쟁력이 높고 리뷰 수가 많으며, 유사 상품 대비 사용자 반응이 좋아 추천되었습니다.

전문 용어는 사용하지 않는다.

CTR 대신 다음 표현을 사용한다.

- 사용자 반응
- 관심도
- 많이 본 상품
- 클릭이 많은 상품
- 반응 좋은 상품

---

## 13. 모바일 UX 원칙

모바일에서는 다음 순서를 우선한다.

검색 영역 → Hero 추천 → 2~4위 추천 → 추천 이유 → 상품 이동

모바일에서는 카드 폭을 100%로 사용하고, 버튼은 손가락 터치에 충분한 높이를 가진다.

---

## 14. Next.js 전환 원칙

Streamlit에서 검증한 기능을 기준으로 Next.js로 전환한다.

전환 전 반드시 정리할 것:

- 추천 모드 정의
- 클릭 로그 구조
- platform_master
- 상품 카드 UI 구조
- API 응답 구조
- 추천 이유 생성 방식

---
