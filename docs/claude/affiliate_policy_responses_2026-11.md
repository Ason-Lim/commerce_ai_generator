## 쿠팡 파트너스 API 가이드 #help/open-api (2026-11-04 브라우저로 확인)
- 파트너스 API는 최종 승인된 회원에게만 제공. Access/Secret Key는 노출 금지(유출 시 문의).
- 호출 한도(문서 탭): GET /products/search "1 분당 최대 50번", reports(/reports/clicks·orders·cancels·commission) "1시간당 최대 500번", 일별 실적은 매일 15:00 업데이트.
- FAQ: "API 종류와 관계없이 비정상적인 과도한 호출은 API 사용제한의 대상", "API 호출 횟수 제한에 도달한 경우 API 사용이 24시간 동안 제한됩니다."
- 이 가이드 페이지에서는 검색 결과의 저장·캐싱·외부 전송에 관한 문구를 찾지 못함 (가이드 범위 한정 — 이용약관·운영정책은 별도 확인 필요).
- 반영: app/services/coupang_rate.py — 대화 서비스·관리자 화면이 같은 키로 1분 45번(설정 COUPANG_SEARCH_PER_MIN, 최대 50)에서 스스로 멈춤. 넘으면 호출하지 않음 (대화: 빈 결과, 관리자: 오류 안내). 테스트 tests/services/test_coupang_rate.py.
- 참고: reports API(클릭·주문·취소·수익)로 백오피스 클릭 통계와 정산 실적을 합칠 수 있음 (미구현).

## 네이버 브랜드커넥트(쇼핑커넥트) 회신 (2026-11-04, 11-04 13:26 문의에 대한 답변)
- 쇼핑커넥트는 "스페이스에 연동한 채널 혹은 본인이 정당한 영향력을 활용해 운영/활동하는 채널"에서 활동 가능.
- "웹 서비스 자체는 이용 주체가 될 수 없고, 본인의 서비스 이용자를 위한 별도의 웹/앱에서의 사용은 정책상 허용되지 않음."
- 외부 웹/앱 활동이 허용되면 별도 공지 예정. 활동 제한 채널 리스트는 네이버 가이드 참조.
- 결론: commerce_ai 사이트 대화 화면·MCP(외부 AI 앱)에는 쇼핑커넥트 링크를 쓸 수 없음. 블로그(applesodda, 스페이스 연동 채널)에서만 사용.

## 반영 (2026-11-04) — 쇼핑커넥트 사이트 노출 끔 (백업 recipe_chat_api_backups/20261104_p28_connect_off_site/)
- `service.connect_on_site()` = `.env` `NAVER_CONNECT_ON_SITE=1` 일 때만 참 (기본 꺼짐). `connect_links()` 는 꺼져 있으면 항상 빈 목록 → 대화 화면·공통 서비스(collect)·MCP 모두 쇼핑커넥트 없음.
- `registry_links()` 로 등록부 읽기 분리 — 블로그 초안의 '발급이 필요한 상품' 점검·급상승 발급 요청은 그대로 동작.
- 사이트 꺼짐이면 대화 검색의 발급 요청(no_match)도 쌓지 않고, 고객에게 '쇼핑커넥트 링크도 아직 없어요' 안내도 보이지 않음.
- 관리자 트렌드 탭 발급 요청 안내에 "링크는 블로그 글에만" 문구 추가. 운영 메모 문구도 블로그 기준으로 변경.
- 테스트: 기존 대화 테스트는 conftest 에서 켠 상태 동작 고정, 기본 꺼짐은 test_site_hides_connect_links_by_default.
