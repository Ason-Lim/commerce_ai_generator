# 제안서 디자인 자산 — 파워포인트 자료 학습·적용 (2026-11-14)

요청: 가지고 있는 파워포인트 자료(아이콘·그림·배경)를 학습해, B2B 제안서 내용에 맞춰 디자인을 적용.

## 자료 (2026-11-14 연결 폴더 '파워포인트 자료')
- 29개: .ppt 14 · .pptx 3 (템플릿 1장씩 — 물류·배송·핀테크·에너지·모바일 앱·타임라인 등), .jpg 12 (아이콘·일러스트 시트 —
  물류 아이콘, 금융 라인 아이콘, 데이터 분석 아이콘, 기기 아이콘, 아이소메트릭 마트·장보기·배송원·창고, 산지직송 일러스트).
- 파일 이름(CK_…)·문구로 보아 **클립아트코리아·통로이미지 스톡**. 이용 허락은 자료를 산 계정의 약관을 따른다 —
  제안서·발표 자료 안에서 쓰는 것은 보통 허용, 그림 파일 자체를 재배포·판매하는 것은 금지. 그래서 자산은 git 에 올리지 않는다(data/ 아래).

## 학습 (`scripts/learn_ppt_assets.py "<폴더>" --pack <이름>`)
1. .ppt → .pptx(LibreOffice) → 슬라이드 속 그림 꺼내기(읽을 수 없는 WMF·EMF 는 건너뜀), 슬라이드 모습·색을 레이아웃 참고로 저장.
2. 그림 시트 → 흰 배경의 가로·세로 빈 줄로 그림을 하나씩 자르고(XY-cut), 테두리에서 이어진 흰 배경만 투명하게(그림 안 흰색은 유지).
3. Claude Sonnet 이 20개씩 보고 종류(icon·illustration·mockup·background·skip)·주제 낱말·어울리는 장을 붙인다.
4. 결과: `data/admin/proposal_assets/<pack>/manifest.json` + 그림. 이번 학습: 206개 → 아이콘 90 · 일러스트 80 · 모형 5 · 배경 2 · 제외 29
   (글자 조각·검은 배경·중복 시트 등). 레이아웃 참고 17장. 다시 실행하면 새 파일만 더한다.
5. 자료 색으로 템플릿 5개 등록: 물류 민트 · 로지스틱 블루 · 프레시 그린 · 핀테크 코랄 · 앱 퍼플 (B2B 콘솔 템플릿 선택에 보임).

## 적용 (`app/admin/b2b/design_assets.py`)
- 장마다 주제 낱말(배송 장 → 배송·택배·트럭…, 폐쇄몰 → 모바일·앱·쇼핑…, 가격 → 돈·결제…)에 공고 품목(식품 → 식료품·마트…)을
  더해 가장 잘 맞는 그림. 한 제안서에서 같은 그림은 한 번만. 배경이 투명한 그림을 우선, 글자가 든 통째 포스터는 피한다.
- PowerPoint: 표지 오른쪽 큰 일러스트, 각 장 제목 오른쪽 아이콘(이어지는 장 제외), 마무리 장 그림.
- HTML 슬라이드: 같은 그림(파일 하나에 넣음 — 줄여서), 표지 그림은 천천히 떠 있는 움직임.
- 자산이 없으면 지금처럼 도형만 (기존 선물 상자 그림).
