## 3. 평가 방식 (S1) — 11-12 블라인드 평가에서 배운 것 반영
- 평가자는 정렬 기준을 모른다. 목록 이름은 질의마다 무작위, 정답표(`var/r4/key_*.json`)는 평가가 끝난 뒤 연다.
- 평가자끼리 답을 보지 않는다. 사용자 → GPT → Gemini 순서와 무관하게 각자 새 대화에서.
- 지난 평가에서 GPT 평가자가 GPT 모델 결과를 1·2위로 고른 일이 있었다. 이번 후보는 모델 출력이 아니라 상품 목록이라 자기 선호 문제는 작지만, 그래도 평가자별 결과를 따로 집계한다.
- 사람 판정(사용자)을 기준으로 삼고, GPT·Gemini 는 '사용자와 얼마나 일치하나'로 본다 — 일치가 높으면 다음 평가부터 AI 판정을 늘릴 수 있다.
- 판단 재료는 우리 서비스가 아는 것만: 상품명·판매처·상품가·중량·100g당. 페이지는 열지 않는다(스크래핑 원칙과 같은 조건).

판정 기준 (미리 정함):
- 현행이 '가격만'(100g당·상품가)보다 사용자 판정에서 뚜렷이 더 많이 이기면 → 품질 점수 유지
- 비슷하거나 지면 → 품질 점수를 순위에서 빼거나 줄이고, 당도 표기는 '판매자 표기' 근거로 화면에만
- 품목 불일치가 특정 정렬에 몰리면 → 관련성 규칙 보완이 먼저

## 결정 (2026-11-12, 사용자) — 포장 단위 수량 계산
- 단가 = (단위당 중량 또는 용량 × 포장 수) ÷ 총가격 기준. `1kg, 2개` → 2kg, `2개, 1kg` → 2kg, `100g 10팩` → 1kg, `190ml, 12개` → 2.28L, `500ml 20병` → 10L.
- 곱하는 단위: 쉼표 앞뒤는 개·팩·봉(지)·박스·상자·병·캔·통·EA, 쉼표 없이 붙은 경우는 '개'를 뺀 포장 단위만(`사과 3kg 10개`는 낱알일 수 있음).
- 곱하지 않음: 낱알 수(입·구·과·수·미)·개입, 서로 다른 중량이 여러 개(옵션 목록), 소수·여러 번 곱하기, 증정.
- p33('100g 10팩'은 개당·전체 불명 → 쓰지 않음)을 이 결정으로 바꿈. 액체는 100ml당, 중량(g)과 섞지 않음.
- 테스트: 채팅·커머스·관리자·나머지 전체 5,649개 통과(클라우드 사본). `reselect_golden` 1개는 저장소 var 의 공공 시세 캐시 때문에 깨지는 기존 실패이며, 캐시 없는 사본에서는 통과.

- 반영(`explain.choose`):
  1. **1위는 가정용 양(3kg·3L 이하)** 에서 100g당 최저. 범위 밖 후보가 있을 때만 "가정용 양(3kg 이하) 후보 n개 중 …"라고 밝힘.
     가정용 양 상품이 하나뿐이면 '가정용 양' 자리로 먼저 보이고, '가성비'(전체 100g당 최저)는 그다음 — 가성비 배지는 정직하게 유지.
     3~5kg 은 '넉넉한 양', 5kg 초과는 대용량(뒤로). 양을 직접 말했거나('귤 5kg') 대용량을 찾으면 적용 안 함. 쌀·물은 대용량 기준의 절반(10kg·12L).
  2. **'당도 표기' 자리**: 상품명에 당도 숫자를 적은 상품(가정용 양 안에서 먼저, 100g당 → 가격 순) —
     "판매자가 당도 11brix라고 적은 상품이에요 (판매자 주장)". '최대·최고 N brix'는 상한이라 제외, '고당도' 말만 있는 상품은 쓰지 않음. 배지 색은 '선물용'과 같은 판매자 표기 계열.
- e2 후보로 미리 본 결과: 감귤 → ① 가정용 양 3kg ② 가성비 5kg ③ 당도 표기 11Brix. 샤인머스캣 → 가성비 1.5kg×2(3kg). 귤 10kg 은 뒤로.
- 남은 연구: 품목별 '보통 사는 양'(굴 3kg 이 '가정용 양' 안에 들어 1위 — 사람·AI 는 1kg 선호), 실제 구매 확인(쿠팡 파트너스 실적 보고 사용 가능 여부 확인 필요).
- 테스트 4개 추가, 기존 2개 수정(가성비 1위 → 가정용 양). 골든은 의도한 변경(관심 상품 비교: 사과 5kg 가성비 → 3kg 가정용 양)만 다시 만듦. 채팅·커머스·관리자·MCP 791, 나머지 4,914 통과.
