## 1. 트렌드 리포트 — 다각 분석 틀

원칙 (GPT 검토): 숫자는 코드, 해석 범위는 **"상위권 키워드 구성의 변화"** 까지. "고객이 옮겨 갔다"·"판매가 늘었다"는 쓰지 않는다. 순위와 검색량은 별개(순위는 상대값).

### 1-A. 시즌성 — 전년 동기 비교 (새로 가능)
키워드마다 **같은 주(±7일) 작년·재작년 순위**를 붙여 네 가지로 가른다.

| 유형 | 판정 (코드) | 리포트 문장 예 |
|---|---|---|
| 반복 시즌 | 작년 같은 주에도 100위 안 | "과메기·굴·귤은 매년 11월 셋째 주 상위권 — 올해도 같은 흐름" |
| 앞당겨짐 / 늦어짐 | 올해 100위 진입일이 작년보다 7일 이상 이르거나 늦음 | "대방어 100위 진입 10-30, 작년 11-12 → 2주 빨라짐" |
| 올해 커짐 / 줄어듦 | 같은 주 최고 순위가 작년보다 50계단 이상 차이 | "절임배추20kg 최고 2위(작년 9위)" |
| 올해 새로 | 작년·재작년 같은 주 500위 밖 | "설아복숭아·답례품·젖산마그네슘은 작년엔 없던 키워드" |

- 부산물: **시즌 달력** — 키워드별 '매년 등장 주간'(2024·2025 두 해에서 100위 안 든 주). 블로그 편성(언제 무엇을 쓸지)의 기준표가 된다.
- 2024 건기식 편중은 '순위 구성 변화' 항목으로 따로 보여 주고, 전년 비교의 기본 해는 **2025**로 둔다.

### 1-B. 배경(계기) — 근거의 등급을 나눠서
| 근거 | 자료 | 등급 |
|---|---|---|
| 달력 사건 | 규칙표: 수능(11월 셋째 목), 빼빼로데이 11-11, 김장철(11월 중~12월 초), 설·추석, 절기(입동·동지), 연말 선물, 새해 다이어트 | **확정** (날짜 자체는 사실) |
| 시즌 반복 | 1-A 의 '반복 시즌' | **강함** (2년 자료) |
| 블로그 제목 단서·글 수 증가, 유튜브 영상 수, 구글 급상승 | 급상승 파일 `blog`·`youtube`·`google`·`cross` | **보통** (함께 움직임) |
| AI 계기 추정(DeepSeek) | 급상승 파일 `cause` | **추정** — 반드시 '추정' 표기, 공개 가능 판정 통과분만 |
| 가격·작황 | `check_kamis.py`(KAMIS 도매가)가 저장소에 있음 — 연결 여부 확인 필요 | 연결되면 **강함** |

리포트에는 근거 등급을 함께 적는다 ("계기: 김장철(달력) + 블로그 글 증가(보통)").

### 1-C. 고객 변화 — 지금 자료로 볼 수 있는 것만
| 보기 | 계산 | 읽는 법 |
|---|---|---|
| **묶음 비중 이동** | 주별 상위 100 안에서 **품목 태그**(과일·수산·정육·곡물·김치/절임·간식·건기식·음료…)와 **용도 태그**(선물·김장·명절·다이어트·간편식…) 각각의 키워드 수 비중. 태그는 **키워드 규칙표**(새 수집 아님). 품목과 용도는 **별도 축** (GPT 검토) | "11월 들어 간식·선물 비중 ↓, 김치/절임·수산 비중 ↑" |
| **단위·포장** | 키워드 끝의 10kg·20kg·5kg·1kg·소포장·낱개 | "쌀20kg > 쌀10kg 유지, 절임배추는 20kg 단위가 상위" — 대용량 선호 지표 |
| **브랜드명 vs 일반명** | 상위 100 중 브랜드·상호가 든 키워드 비율(규칙표 + 등록부 스토어명) | 특정 브랜드 쏠림(설아복숭아·고래사어묵·도미솔김치)은 '바이럴·행사' 신호 |
| **건기식 vs 신선식품** | 품목 태그 집계 | 2024→2026 구성 변화의 핵심 |
| **우리 고객 검색어와의 거리** | `surge.chat_search_terms`(앱 /api/chat 검색어) vs 데이터랩 상위 | "네이버에선 뜨는데 우리 고객은 아직 안 찾음" = 블로그로 끌어올 후보 |
| 안 되는 것 | 연령·성별(데이터랩 API 는 되지만 수집 안 함), 판매량·전환, 가격대 | 한계 절에 적음 |

### 1-D. 키워드 생애주기
- 이미 구현한 **흐름 단계**(등장→상승→정점→하락/정착, 주 평균)와 급상승 파일의 `status`(surging·new·spike_faded)를 합쳐 **'지속형 / 일회성 튐'** 을 가른다. 일회성(한 번 튀고 꺼짐)은 블로그 대상에서 뺀다.

### 1-E. 리포트 구성 (한 편)
1. **한눈에** — 기간·관측일·빠진 날, 반복 시즌 n개 / 올해 새로 n개 / 식은 n개 (숫자)
2. **시즌 비교** — 1-A 표 (올해 vs 작년 같은 주), 앞당겨진 것·커진 것 상위 5
3. **올해 새로 뜬 키워드** — 배경 근거 등급과 함께 (1-B)
4. **상위권 구성 변화** — 품목·용도 비중, 단위, 브랜드 비율 (1-C) 그래프 1~2개
5. **키워드별 한 줄** — 흐름 단계 + 근거 (2절 화면과 같은 계산)
6. **다음 2~4주 예상 (달력 기반)** — 시즌 달력에서 **작년 이맘때 다음에 올라온 키워드** 목록 ("작년 11월 넷째 주엔 동지팥죽·대게·곶감이 올라왔어요") — 예측이 아니라 '작년엔 이랬다'로 씀
7. **한계** — 순위≠검색량, 판매 자료 없음, 2024 구성 차이, 계기는 추정

생성: 숫자·표는 코드(`app/services/trends/report.py` 새 모듈, `period.py` 재사용), 문장은 **템플릿 기본** + 선택적으로 DeepSeek 로 다듬기('AI 정리' 표시, 숫자 변경 금지 검사). 저장 `var/trends/period_reports/report_{start}_{end}.json|md`, 화면은 관리자 '기간별 순위 변화' 아래 '리포트 만들기' 버튼.

## 2. 블로그 — 급등 키워드별 '상품성 있는 상품' + 콘텐츠 조합

### 2-A. 대상 키워드 고르기 (리포트 → 블로그로 넘기는 문턱)
1. 급상승 파일 `surging`·`new` 이거나 기간 조회 **개선폭 상위**이고,
2. 생애주기가 **상승~정점** (하락·일회성 제외),
3. **쇼핑 링크가 있거나 발급 가능**(등록부 또는 브랜드커넥트 검색 결과 1건 이상),
4. 건강 효능 표현이 필요한 건기식은 **표현 제약이 크므로 후순위** (아래 2-E).

### 2-B. 상품성 판단 — '링크 있음' ≠ '소개할 상품 있음' (GPT 검토)
| 단계 | 기준 | 자료 |
|---|---|---|
| ① 관련성 | 상품명·카테고리가 키워드의 **종류와 용도**에 맞음 (대방어 → 대방어 회/필렛, '방어 낚시대' 아님) | 등록부 키워드·상품명, 브랜드커넥트 검색 |
| ② 사회적 증거 | 리뷰 수·평점 — **확인 날짜와 상품 식별자(링크)** 를 함께 저장·표기 (마지막 전체 수집 11-13) | shop_monitor.db, 확장 '발급 링크 관리' 읽기 |
| ③ 쓸 수 있음 | 링크 유효·판매 중 (초안 만들 때 사람이 확인) | 수동 |
| ④ 고객 적합 | 가격대·용량 선택지가 2~3개 (대용량/소포장), 배송(신선식품은 당일·새벽 여부) | 상품명에서 규칙 추출 (가격은 글에 안 씀) |
| 참고 | 수수료율은 **운영자 참고 칸**, 고객 적합 점수에 안 넣음 | 등록부 |
- 점수는 ①→②→④ 순 (관련성 미달이면 탈락), 키워드당 **1~3개**. 리뷰가 많다는 이유로 '품질이 좋다'고 쓰지 않음.

### 2-C. 키워드 유형별 글 틀 (유형이 콘텐츠 조합을 정함)
| 유형 | 예 | 글의 축 | 레시피·영상 역할 |
|---|---|---|---|
| 제철 식재료 | 대방어·과메기·굴·도루묵·대봉감 | 지금이 제철인 이유(달력·작년 비교) → 고르는 법 → 손질·보관 → 상품 | 레시피(먹는 법 2~3) + 손질 영상 링크 — **구매 뒤 실패 불안을 줄임** |
| 시즌 이벤트 | 수능선물·빼빼로·답례품·크리스마스 | 날짜까지 남은 기간 → 용도별(학생·동료·거래처) 추천 → 수량·포장·배송 마감 | 레시피는 '만들기'(빼빼로만들기 ↔ 완제품) 한 줄, 영상은 선물 포장 |
| 김장·저장식 | 절임배추20kg·김장용생새우·새우젓·생강 | 일정(김장철 주간) → **양 계산**(4인 기준 배추 n포기당 젓갈 g) → 상품 묶음 | 레시피(김치 종류별) + 영상(절이는 법) — 묶음 구매 유도 |
| 신상·바이럴 | 설아복숭아·볶음너구리·두바이쫀득쿠키 | 왜 뜨는지(블로그·유튜브 증가) → 솔직한 기대치 → 품절·대체 상품 | 영상 링크 비중 높음, 레시피는 '활용법' |
| 건기식 | 젖산마그네슘·오메가3 | **성분·함량·섭취 안내만**, 효능·치료 표현 금지 | 레시피·영상 없음, 전문가 상담 문구 |

### 2-D. 글 한 편의 구조 (상품 중심, 트렌드는 도입 1~2줄)
1. 쇼핑커넥트 고지 (맨 위, 승인 시) 
2. **훅** — "요즘 ○○ 검색이 평소의 n배 / 작년보다 2주 빨리 올라왔어요" (1~2줄, 리포트 숫자)
3. **왜 지금** — 시즌·달력·배경 1단락 (근거 등급 '보통' 이상만, 추정은 '~로 보여요')
4. **고르는 법 3가지** — 유형별 체크리스트 (크기·원산지·손질 여부 등 사실 기준)
5. **상품 1~3** — 각: 상품명·판매처·'리뷰 n개·평점 x (m-d 확인)'·한 줄 이유(관련성 기준) · 쇼핑커넥트 삽입 자리. 가격 없음
6. **바로 해 먹기** — 레시피 1~2 (앱 레시피 서비스 `food_get_recipe` 결과를 요약, 상세는 앱 링크) 
7. **영상으로 보기** — 유튜브 **제목·채널·링크만** (임베드·캡처·내용 복제 금지), 최근 영상 우선
8. **보관·주의** — 신선식품 보관일, 배송 유의
9. **한 가지 행동** — "지금 주문하면 ○요일 도착 / 김장 전 주까지 준비" 식의 CTA 1개
10. 출처·면책 — 데이터랩 상대 지수, 순위, 확인일, 원인은 추정, 가격·재고는 판매처
