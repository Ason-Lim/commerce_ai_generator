# '요즘 뜨는 식품' 답변 · 급상승 리포트 유튜브 근거 · 구글 예시 데이터 발견 (2026-11-06 p48)

## 문제 (사용자 화면 PDF)
- '요즘 뜨는 식품' → 문장 그대로 쿠팡 검색 → 상품명에 '요즘 뜨는'이 적힌 생수 36개·하스카프베리 건강식품이 추천됨.

## 바꾼 것
- **대화**: 트렌드 말(뜨는·핫한·유행·인기·요즘 잘 팔리는 …)이 있고 구체 상품명이 없으면 쿠팡에서 문장을 검색하지 않고
  매일 아침 급상승 리포트(var/trends/surge_YYYY-MM-DD.json)로 답한다 (`app/services/chat/hot.py`, stage `shopping_hot`).
  - '요즘 인기 있는 사과' (상품명 있음) → 평소 쇼핑 / '요즘 유행하는 요리·레시피·음식' → 레시피 트렌드(기존) / '인기순으로' → 아님
  - 분류: 과일·해산물·간식·라면·김장·고기·선물 ('요즘 유행하는 과일') — 맞는 식품이 없으면 그렇다고 말하고 전체 목록
  - 화면: `trend_list` 블록(배수·시작일·식품 순위·블로그/순위/유튜브 신호·AI 추정 계기·30일 그래프) + 위 3개 식품의 상품 2개씩
  - 상품 카드 첫 사유 = 검색 증가 사실, 근거 종류 **검색 트렌드**(basis `trend`). 상품은 제목에 그 식품 이름이 있을 때만
    (실제 결과: '볶음너구리'에 불닭볶음면 세트가 섞였던 것을 막음)
  - 출처 고지: 확인한 곳 / 쓰지 않은 곳(연결 전), "검색 증가는 관심의 신호일 뿐 맛·품질·안전을 뜻하지 않음"
  - 식품 이름 칩 → '{식품} 추천해줘' (평소 쇼핑)
- **급상승 리포트에 유튜브 근거** (`surge.youtube_evidence`): 최근 7일 영상 수 vs 한 달 전 같은 7일(36~29일 전, 데이터랩 '평소' 구간 안).
  제목에 식품 이름이 있는 영상만, 제목·게시일·링크만. 2배 이상 & 5개 이상이면 증가.
  검색 1번 상한(50개)에 걸리면 '이상'으로 표시하고 확실할 때만 판정(모르면 교차 확인 분모에서 뺌 — 모름≠늘지 않음).
  - 상위 12개(TREND_YOUTUBE_TOP) × 2번 = 하루 약 2,400 할당량(기본 10,000). 내일 10시 자동 실행부터 포함.
  - 처음 시도한 '최근 2주 vs 그 전 2주'는 실제 실행에서 인기 식품 대부분이 두 기간 모두 상한에 걸려 버림.
  - 오늘 리포트에는 `python -m scripts.update_trend_surge --youtube-only` 로 덧붙임 → 볶음너구리(48개 이상 vs 4)·수능선물·도루묵·삼립호빵 증가 확인.
- **구글 트렌드 CSV는 예시(stub) 데이터**: food-trend-automation `collectors/google.py` 가 기본값 `use_stub=True` 로
  날짜 시드 고정 단어 22개(헬스·에어프라이어·김치 …)를 무작위로 뽑아 trends_v4 CSV 를 만든다. 실제 구글 값 아님.
  → `GOOGLE_TRENDS_VERIFIED=1` 일 때만 근거로 사용(기본 꺼짐), 이전 리포트도 고객 화면에서 구글을 근거로 치지 않음.
  - 네이버 식품 순위 CSV 는 실제 값(datalab 쇼핑인사이트 순위, 단 공식 API 가 아닌 datalab 내부 주소 요청 — 별도 검토 거리).
  - 실제 구글 연결 길: 구글 트렌드 공식 API(알파, 신청 필요) 또는 pytrends(비공식) — 결정 대기.
