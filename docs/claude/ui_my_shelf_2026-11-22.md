# 창 3-B — 고객 화면 '내 보관함' (2026-11-22)

로드맵 '고객 화면 상세: 내 보관함'(2026-11-18 결정) 그대로. 브랜치 `ui/my-shelf`.

## 화면
- 주소 `/#/me`. 입구: PC 머리줄 오른쪽 **사람 아이콘**(관심 상품 버튼을 합침, 관심 상품 수 배지 — 대화 시작 전에도 보임) · 모바일 **아래 탭 4번째 '내 보관함'**. 지금 뜨는 식품·서버 트렌드 글 페이지도 같은 아이콘·탭.
- 칸 넷:
  | 칸 | 내용 | 저장 |
  |---|---|---|
  | 최근 검색 | 이 브라우저가 쓴 대화(최근 5개 세션)의 검색 최근 5개(같은 검색어는 하나) + '다시 묻기' | 서버 대화 기록 (`GET /api/me?owner&sessions`) |
  | 관심 상품 | 검색별 묶음, 확인 시각 가격, '○○에서 보기 ↗'(`/go` 경유), '관심 상품 비교하기'(대화로) | 서버(브라우저별 보관함 주인 값) |
  | 장보기 목록 | 레시피 '부족해요·없어요' 재료 상품 — **대화 칸과 같은 내용**(브라우저 `ai-food-basket`), '새 대화'를 눌러도 남음, 대화 칸에 '내 보관함에서 보기' | 브라우저 |
  | 설정 | 채식(고기 상품 표시)·맵지 않은 것(매운 상품 표시)·가구 인원·피하고 싶은 재료 + '표시 대신 숨기기' | **기기 안에만**(`ai-food-prefs`, 서버로 보내지 않음) |
- 설정은 대화 상품 카드에 "내 보관함 설정: 상품명에 '○○'가 있어요 — 원재료·알레르기 표시는 판매처에서 꼭 확인하세요" 표시, 숨기기를 켜면 그 카드만 빼고 "설정으로 n개 숨겼어요(순서는 그대로)". **순위 점수·순서 불변**(화면에서만).
- 알레르기는 받지 않음 — '피하고 싶은 재료', 안전 보증 문구 없음.
- **기록 지우기**: 확인 창 → `POST /api/me/forget {owner, sessions}`(서버 관심 상품 비움 + 그 세션들의 대화 상태·레시피 대화 상태 초기화) + 브라우저 장보기·설정·세션 목록·현재 대화 값 삭제.
- 로그인 없음(4단계 SSO 때), '장바구니'·'주문' 문구 0 (배송비 'confirmed' 안내 "주문 단계 계산" → "판매처 결제 단계에서 계산").
- 예전 관심 상품 옆 패널(`SavedPanel`)은 보관함으로 옮겨 지움.

## 서버
- `ChatService.shelf_view(owner, sessions)` · `forget(owner, sessions)`, 라우트 `GET /api/me`, `POST /api/me/forget`(`extra=forbid` — 설정 값 자리 없음).

| 서버 실패 때 식별자를 먼저 지우면 재시도 불가 | 서버 삭제가 **성공한 뒤에만** 브라우저 기록을 지움 — 실패하면 아무것도 지우지 않고 다시 시도 안내(화면 시험). 성공하면 **보관함 주인 값을 새로** 만들어 예전 값으로 닿지 않게 |
| 다른 탭·새로고침 | 장보기·설정은 탭 사이 동기화, 서버 기록은 새로고침 때 빈 상태(화면 시험). 다른 탭에 열린 대화는 새로고침 안내 |
