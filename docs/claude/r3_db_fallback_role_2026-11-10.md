# R3 — DB 예비 경로의 역할 결정안 (2026-11-10 작성 · 2026-11-16 결정·적용: ④ 폐지)

## 결정 (2026-11-16, 사용자)
- **④ 예비 경로 폐지**. 주 경로(쿠팡 실시간)가 실패하면 과거 가격·오래된 상품 목록을 보여 주지 않는다.
- 근거: 2026-11-16 R0 — 경로 기록 대화 4개 모두 주 경로, 예비 경로 0건. 고객 신뢰 우선·근거 없는 말 안 하기 원칙과 맞음.
- R4(② 비교 평가)는 하지 않는다.

## 적용 (2026-11-16, PR #6 → main `182035a`)
- `/recommendations/nl`: 실패 시 빈 결과 + `recommendation_path: provider_failed`. `.env` 에 `RECO_DB_FALLBACK=1` 이면 예전 동작
- 채팅: "'<검색어>' 상품을 불러오지 못했어요. 잠시 후 다시 시도해 주세요." + 네이버쇼핑 검색 링크(제휴 아님) + 같은 질문 다시 찾기 칩. '찾지 못했어요'는 함께 말하지 않음
- 실수 신호 `source_failed` (주간 보고: '쿠팡을 불러오지 못함')
- `db_fallback_recommendations` 함수는 관리자 근거 화면·연구 스크립트용으로 유지. 순위 스냅샷은 이 함수를 직접 불러 s 시리즈 기준점 유지
- 확인: 전체 테스트 5,743 통과 · 5 건너뜀 · 실패 0 / 순위 s8→s9_r3 63/63 같음 / 화면 d8→d9_r3 11/11 같음
- 서버 재시작 후 적용됨
