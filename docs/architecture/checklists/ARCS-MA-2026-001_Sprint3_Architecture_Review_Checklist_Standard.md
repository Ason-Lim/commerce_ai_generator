# 3. Mandatory Review Checklist

## A. Evidence Completeness

* [ ] ADA approved
* [ ] Implementation evidence available
* [ ] Test evidence available
* [ ] Regression evidence available
* [ ] Reproducible verification completed

---

## B. Integration Verification

* [ ] IVR
* [ ] IPR
* [ ] IPS
* [ ] IRC
* [ ] IRR
* [ ] IRG
* [ ] IVC

All required verification stages shall be completed before Architecture Completion review.

---

## C. Architecture Review

* [ ] OAA completed
* [ ] Architecture observations reviewed
* [ ] Architecture boundaries preserved
* [ ] Governance compliance verified

---

## D. Architecture Completion

* [ ] AVCR completed
* [ ] MACR completed
* [ ] Domain ready for handoff

---

## E. Governance Compliance

Verify compliance with:

* [ ] Evidence First Principle
* [ ] Progressive Maturity Model
* [ ] Role-based Governance
* [ ] Responsibility Separation
* [ ] Architecture Promotion by Evidence

---

## F. Architecture Observations

Confirm that:

* [ ] observations are documented;
* [ ] attribution is supported by evidence;
* [ ] blocking status is identified;
* [ ] future disposition is recorded.

---

## G. Traceability

Confirm that:

* [ ] governing references are complete;
* [ ] approval chain is traceable;
* [ ] repository locations are correct;
* [ ] evidence links are preserved.
