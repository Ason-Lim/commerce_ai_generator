# 1. Purpose

This document establishes the official template standard used for Architecture Review documents throughout Sprint 3.

The objective is to ensure that Architecture Reviews remain:

* consistent;
* reproducible;
* traceable;
* evidence-based;
* independently reviewable.

# 3. Standard Review Structure

Every Architecture Review document shall contain the following sections.

```text
Document Identity

Purpose

Governing References

Review Summary

Architecture Assessment

Evidence Assessment

Governance Conformance

Architecture Observations

Official Decision

Next Authorized Stage
```

---

# 4. Mandatory Review Statements

Every review shall include:

## Review Result

```text
APPROVED

or

CONDITIONALLY APPROVED

or

REVISION REQUIRED

or

REJECTED
```

---

## Architecture Assessment

The assessment shall distinguish:

* verified facts;
* assumptions (if any);
* evidence limitations.

---

## Governance Conformance

The review shall explicitly confirm consistency with:

* Evidence First Principle;
* Progressive Maturity Model;
* Role-based Governance;
* Responsibility Separation.

---

## Official Decision

The review shall conclude with:

```text
Review Result

Approved Stage

Next Authorized Stage
```

---

# 5. Architecture Observation Format

Observations shall be recorded separately from implementation findings.

Each observation shall identify:

* observation description;
* verified evidence;
* attribution;
* blocking/non-blocking classification;
* recommended disposition.

---

# 6. Traceability Requirements

Every review shall identify:

* reviewed document;
* governing references;
* evidence sources;
* approval authority;
* subsequent governance stage.

---

# 7. Template Applicability

This template standard applies to:

* OAA
* AVCR
* MACR
* Architecture Review Reports
* Architecture Approval Reports

Other architecture documents may adopt this template where appropriate.
