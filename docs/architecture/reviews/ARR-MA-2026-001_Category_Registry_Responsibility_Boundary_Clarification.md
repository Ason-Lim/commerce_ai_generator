# ARR-MA-2026-001

## Category Registry Responsibility Boundary Clarification

| Item | Value |
|---|---|
| Decision Authority | 00_1 Master Architecture |
| Status | OFFICIAL ARCHITECTURE DECISION |
| Result | APPROVED |
| Effective Date | 2026-08-04 |

## Decision

**Option A — APPROVED**

```text
Category Registry:
High-level category identification and routing

Domain Provider:
Representative domain vocabulary and domain interpretation
```

**Option B — DEFERRED**

The Category Registry shall not become a comprehensive domain-vocabulary registry during Sprint 3.

## Category Registry Responsibilities

- High-level category identification
- Category aliases
- Routing metadata
- Provider linkage

## Domain Provider Responsibilities

- Representative vocabulary
- Domain terminology
- Product-specific expressions
- Canonical interpretation
- Attribute extraction

## Sprint 4 Observation

A separate Alias Resolution Layer may be evaluated after Sprint 3. It shall not be implemented by expanding Category Registry responsibilities.

HIGH-LEVEL ROUTING APPROVED
DOMAIN VOCABULARY OWNED BY DOMAIN PROVIDERS
