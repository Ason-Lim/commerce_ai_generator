AO-MARKETPLACE-005
Deduplication Group platform_count Semantics
Resolution Evidence

Date: 2026-08-15
Status: RESOLVED

1. Classification

AO-MARKETPLACE-005 was classified as a CONTRACT DEFECT.

The previous deduplication implementation defined:

platform_count = len(grouped_items)

This caused multiple offers from the same platform to be
incorrectly interpreted as multiple platforms.

2. Corrected Contract

The canonical deduplication group contract is:

platform_count
    Number of distinct non-empty platforms represented
    in the deduplication group.

item_count
    Number of offers/items contained in the
    deduplication group.

items
    Complete grouped offer collection.

3. Runtime Remediation

app/services/market/deduplicator.py

platform_count now counts distinct non-empty platform
identifiers.

item_count was introduced to preserve explicit grouped
offer cardinality.

4. Contract Verification

Dedicated contract:

tests/services/market/
test_marketplace_deduplication_platform_contract.py

Verification scenarios:

    item_count = 2

two platforms / 2 offers
    platform_count = 2
    item_count = 2

repeated platforms / 3 offers
    platform_count = 2
    item_count = 3
