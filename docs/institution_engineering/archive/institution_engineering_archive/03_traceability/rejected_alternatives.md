# Rejected or Superseded Alternatives

This initial snapshot does not yet contain enough direct source evidence to
classify earlier ideas as formally rejected.

Use the following lifecycle for future records:

```text
PROPOSED -> CHALLENGED -> REVISED -> SUPERSEDED
```

Each rejected or superseded item should record:

- original statement
- source turn
- challenge or counter-evidence
- authority or process that changed its status
- replacement concept
- whether reconsideration is allowed
